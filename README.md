## 📖 About

Meshmixer is a mesh editing tool built for 3D printing, digital sculpting and model cleanup. It started as an Autodesk research project and is widely used for mixing parts, generating support structures, hollowing solids and repairing broken geometry. The 2026 build focuses on stability fixes, smoother brush response on dense meshes and improved file import handling.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes immediately | Check that the download finished completely, then run the file again as administrator. |
| App opens with a blank viewport | Update your graphics driver and confirm the GPU supports DirectX 11. |
| Import fails on large STL files | Reduce the file size in your source tool or increase available RAM. |
| Sculpt brushes feel laggy | Lower the mesh density with the decimate tool before sculpting. |
| Support generation takes a long time | Close background apps and retry with a lower support density setting. |
| Windows cannot find the app after install | Search "Meshmixer" in the Start menu and pin it for quick access. |
